# ERQLABS Studio: versiones firmadas

Este repositorio solo guarda los paquetes publicados de ERQLABS Studio y su manifiesto firmado. El código fuente es privado.

Cada `manifest.json` está firmado con minisign (`manifest.json.minisig`), y el Studio no cree un manifiesto cuya firma no coincida. ERQLABS Studio es software privado, todos los derechos reservados: se usa solo con permiso de su dueño.
